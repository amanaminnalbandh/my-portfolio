# 💻 Amanul Amin Nalbandh | Developer Portfolio

A production-grade, enterprise-themed developer portfolio built to showcase full-stack web applications, cloud infrastructure architecture, and data science projects. 

**Live Demo:** [aman-code.vercel.app](https://aman-code.vercel.app/)

---

## ✨ Core Features

* **Live GitHub Synchronization:** Automatically fetches and displays the latest public repositories using the GitHub REST API (`/users/amanaminnalbandh/repos`). No manual project card updates required.
* **Enterprise UI/UX Architecture:** Designed with a dark-mode "crimson glow" aesthetic, featuring a split-hero layout, monochrome tech strip, and a CSS Grid "Bento box" capabilities section.
* **Full-Stack Contact Pipeline:** Integrated frontend form connected to a custom Node.js/Express backend utilizing Nodemailer for direct email delivery.
* **Responsive & Performant:** Fully responsive across mobile, tablet, and desktop viewports, engineered with Next.js App Router and Tailwind CSS.
* **Direct Resume Delivery:** Hosts a highly optimized, ATS-compliant PDF resume directly in the `/public` directory for instant recruiter access.

## 🛠️ Tech Stack

* **Frontend Engine:** Next.js (React), TypeScript
* **Styling & UI:** Tailwind CSS (Custom ambient lighting, gradients, and grid layouts)
* **External APIs:** GitHub REST API
* **Backend Integration:** Node.js, Express, Nodemailer (Running independently)
* **Deployment:** Vercel (CI/CD connected to this GitHub repository)
